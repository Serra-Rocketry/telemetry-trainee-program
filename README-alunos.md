# Treinamento Telemetria - Guia Rapido do Aluno

Bem-vindo ao treinamento do time de telemetria da Serra Rocketry.

## Como comecar

1. Faça fork do repositorio e clone o seu fork
2. Leia o [Guia do Aluno](docs/guia-do-aluno.md)
3. Veja o [Roadmap do Treinamento (9 semanas)](docs/roadmap.md)
4. Siga a semana atual em [Semanas](docs/semanas/README.md)
5. Entregue dentro de `entregas/nome-sobrenome/semana-XX/` (veja o [Padrão de Entregas](docs/padrao-entregas.md))

## Regras basicas

- Trabalhe na `main` do seu fork
- Cada entrega vira um PR (do seu fork para a `main` original)
- Entrega em `entregas/nome-sobrenome/semana-XX/`, sem apagar o material do repo
- README da semana com instrucoes sempre
- A cada semana, sincronize o fork e abra uma nova PR

## Onde tirar duvidas

- Revisao semanal de PR
- Issue aberta com sua pergunta
