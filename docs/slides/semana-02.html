Contexto

Durante o voo, o foguete envia os pacotes por rádio e o computador da base recebe tudo como um log cru.

  • Misturado com mensagens do receptor e pacotes incompletos

Formato do Pacote

Mesmos 24 campos da Semana 1, separados por vírgula:

ID, millis, pckt, alt, temp, humi, press,
gx, gy, gz, ax, ay, az, vz, maxalt, state,

Atenção às linhas [LoRa]

A linha [LoRa] RX também contém um pacote, mas incompleto:

  • Vem sem os campos hora e data → 22 campos, não 24
  • O rssi vem zerado (o valor real está no texto RSSI=...)

O parser deve rejeitá-la (contagem de campos diferente de 24).

Parser de Pacotes

COLUNAS = ["ID", "millis", "pckt", "alt", "temp", "humi", "press",
           "gx", "gy", "gz", "ax", "ay", "az", "vz", "maxalt", "state",
           "hora", "data", "gps_alt", "lat", "lon", "sat", "pqd", "rssi"]

def parse_packet(linha):
    linha = linha.strip()
    pos = linha.find("#51,")
    if pos == -1:
        return None                     # nao e um pacote

    campos = linha[pos:].split(",")
    if len(campos) != 24:
        return None                     # incompleto (ex.: [LoRa] RX)

    try:
        dados = dict(zip(COLUNAS, campos))
        dados["ID"] = int(dados["ID"].lstrip("#"))
        for nome in COLUNAS[1:]:
            dados[nome] = float(dados[nome])
        return dados
    except ValueError:
        return None                     # campo nao numerico

Validação de Range

LIMITES = {
    "alt":   (-100, 10000),   # metros
    "temp":  (-40, 85),       # Celsius
    "press": (300, 1100),     # hPa
    "lat":   (-90, 90),
    "lon":   (-180, 180),
    "sat":   (0, 30),
    "rssi":  (-140, 0),       # dBm
}

def validar(pacote):
    for campo, (min_v, max_v) in LIMITES.items():
        if not (min_v <= pacote[campo] <= max_v):
            return False
    return True

Pipeline de Processamento

def processar(caminho):
    total = validos = parse_err = valid_rej = ignoradas = perdidos = 0

    with open(caminho) as f:
        for linha in f:
            linha = linha.strip()
            if not linha:
                continue
            total += 1

            if linha.startswith("["):        # [LoRa], [STATS], [MESH], [LOST]
                ignoradas += 1
                if linha.startswith("[LOST]"):
                    perdidos += int(linha.split("perdido")[0].split()[-1])
                continue

            pacote = parse_packet(linha)
            if pacote is None:
                parse_err += 1
            elif not validar(pacote):
                valid_rej += 1
            else:
                validos += 1

    return total, validos, parse_err, valid_rej, ignoradas, perdidos
